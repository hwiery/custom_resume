# Custom Resume Generator (커스텀 이력서 생성기)

## 개요
커스텀 이력서 생성기는 사용자가 자신의 삶의 경험을 문서화하고, 맞춤형 이력서를 작성하며, 이력서를 생성할 수 있도록 돕는 Python 기반 애플리케이션입니다. 
이 애플리케이션은 Python 기반으로 하고, 입력을 위해 Markdown 파일을 사용하며, PDF 및 DOCX와 같은 형식으로 자동 생성합니다.

## 기능
- 사용자가 자신의 삶의 경험을 작성하면서 대화하듯 작성하여 LLM과의 대화를 통해 얻어진 정보를 바탕으로 이력서를 작성하게 됩니다.
  이로인해 예상하지 못했던 기억이나 작은 기록들을 추가할 수 있으며 업무 관련 성과 및 중요한 사건을 빠짐없이 기록할 수 있습니다.
- 만들어진 문서를 바탕으로 LLM이 질문하게 될 것이고, 사용자가 특정 질문에 대한 답변을 작성하면 더욱 완성도 있는 문서로 만들 수 있습니다.
- 문서화된 히스토리와 Q&A 응답을 바탕으로 만들어진 이력서 초안을 LLM을 통해 프롬프트로 적절하게 질문하여 Reference 문서와 비슷한 양식을 갖추면서 이력서의 양식으로 탈바꿈하게 됩니다. 
- 미리 준비된 채용 웹사이트에서 검색어를 통해 검색하여 원하는 채용공고를 찾습니다. 
  그렇게 찾은 특정 채용 공고에 맞춰 LLM을 통한 프롬프트로, 만들어진 이력서를 채용공고에 적합한 이력서로 커스터마이징 할 수 있게합니다.
- 마지막으로 python 코드를 통해 정리된 이력서를 PDF 및 DOCX 형식으로 자동 생성합니다.

## 서비스 규칙
1. 히스토리 문서화:
   - 자신의 삶의 경험을 작성하고, 업무 관련 및 기억에 남는 사건을 문서화합니다.
   - 영향을 미친 분야에서의 성과를 기록합니다.

2. 질문에 대한 답변:
   - 특정 질문에 대해 구체적으로 답변합니다.
   - 답변을 모아 Q&A 문서를 완성합니다.

3. 초안 작성:
   - Q&A 문서와 참조 문서를 사용하여 잘 구조화된 이력서를 작성합니다.

4. 채용 공고 맞춤화:
   - 채용 공고 웹사이트를 방문하여 적절한 채용 공고를 찾습니다.
   - 발견한 채용 공고의 내용을 저장하고, 이에 맞춰 이력서를 커스터마이즈합니다.

5. 파일 생성:
   - `create_resume.py` 스크립트를 사용하여 대상 기업명을 포함한 이력서를 생성합니다.
   - 지정된 폴더에 결과물을 저장합니다.

## 파일 구조
- `create_resume.py`: DOCX 형식의 이력서를 생성하는 스크립트.
- `create_resume_pdf.py`: PDF 형식의 이력서를 생성하는 스크립트.
- `QNA.md`: 사용자의 경험에 대한 질문과 답변이 포함된 문서.
- `reference.md`: 잘 구조화된 이력서 템플릿이 포함된 참조 문서.
- `업체리스트`: 관련 채용 공고를 찾기 위한 웹사이트 목록.
- `hy coverletter_en_일반.md`: 커버 레터 템플릿.
- `hy 이력서_ko_디폴트2.md`: 기본 이력서 템플릿.

## 사용법
1. 히스토리 문서화: 개인의 히스토리와 경험을 Markdown 형식으로 작성합니다.
2. 질문에 대한 답변: Q&A 문서를 작성하여 구체적인 답변을 포함합니다.
3. 이력서 초안 작성: 제공된 스크립트를 사용하여 히스토리와 Q&A를 바탕으로 이력서를 생성합니다.
4. 채용 공고 맞춤화: `업체리스트`에서 채용 공고를 추출하고, 이력서를 맞춤화합니다.
5. 출력 생성: 원하는 형식으로 이력서를 생성하기 위해 적절한 스크립트를 실행합니다.

## 시작하기
애플리케이션을 시작하려면 리포지토리를 클론하고, 필요한 라이브러리와 함께 Python이 설치되어 있는지 확인합니다. 스크립트의 지침에 따라 문서를 생성합니다.

## 결론
이 애플리케이션은 개인의 히스토리를 문서화하고 맞춤형 이력서를 생성하는 과정을 간소화하여 사용자가 잠재적인 고용주에게 효과적으로 자격을 제시할 수 있도록 돕는 것을 목표로 합니다.
